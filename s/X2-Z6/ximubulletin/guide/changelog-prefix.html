《变更日志类型前缀与 Breaking 标注规范》
指引编号 XB-CL-2026-08 · 自 2026-05 起适用

发布清单对变更日志逐条校验：每条目须携带类型前缀与说明文字， 在册类型前缀集合如下：

前缀含义
feat新增能力
fix缺陷修复
perf性能改进
docs / test / chore 文档 / 测试 / 构建与杂项

Breaking 标注

  • 含不兼容变更的条目须在说明尾部追加 ! 并在正文说明迁移方式；
  • 补丁版（patch）不得包含 Breaking 条目，否则清单校验不予通过；
  • 条目按 类型 + 范围 + 说明 三段式登记，范围为受影响模块。
