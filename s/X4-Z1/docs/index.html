产品概览

InsightBridge 是面向业务团队的自助式分析连接器平台：一次接入，即可在 WorkHub 工作台内对授权数据域执行受控查询。平台负责鉴权、字段映射与查询审计，业务侧无需 维护任何数据管道。

核心能力

  • 连接器化接入：每个数据域一个连接器，权限边界清晰、可随时回收；
  • 最小授权模型：连接器仅请求其数据域所需的 scope（如 sales:read）；
  • 扩展能力：组织级聚合报表（org_aggregate）等扩展能力须经控制台「权限审批」通道获批后生效（审批票号 + 排队冷却），凭证有效期以平台公告为准；
  • 查询审计：所有查询在 WorkHub 与 InsightBridge 双侧留痕。
