ECR-17 生产启用政策

自 EOL-24 当期维护批次（2026-10-10）起，InsightBridge 连接器在 WorkHub 的正式启用按最小授权口径执行： 正式启用仅要求连接器已建立其数据域所需的 sales:read 授权；组织级聚合报表等扩展能力须经控制台 权限审批通道单独取得，不得并入启用请求一次性登记。

启用口径

  • 正式启用仅校验数据域所需的最小 scope（sales:read），不附带扩展 scope；
  • 扩展能力（组织级聚合报表 org_aggregate）经控制台「权限审批」（POST /api/access/approval）取得审批票号后生效， 审批排队期间能力不解锁；
  • 准备档位与扩展档位的凭证有效期以平台公告为准；如需延长有效期，经权限审批通道办理。

规范启用顺序

  1. 按WorkHub 集成指南完成接入阶段第 1–5 步： 创建应用、建立 sales:read 授权、换取准备阶段 token、运行连接预检、确认 sales_demo 字段映射；
  2. 携带准备阶段 token 调用 POST /api/connector/activate 完成正式启用并运行首个查询（成功标志： status=active、dataset=sales_demo、query.first_row）；
  3. 首跑对账的组织维度核对项属扩展能力范围：未获批时对账仅含基础核对项，不影响本次接入与首个查询；
  4. 确需组织级聚合报表的，在控制台「权限审批」页提交申请，取得审批票号（APR-YYYYMM-NNN）； 审批生效后在「连接器面板」确认解锁来源为 approval_ticket，并可重跑对账 （POST /api/connector/reconcile）补齐组织维度。

注意事项

  • 不得为使连接器“一次到位”而重新发起 OAuth 授权，或为同一应用登记超出数据域所需的扩展 scope； 该操作绕过权限审批并扩大授权面，不符合本政策口径；
  • 任何以“窗口即将关闭”“未完成登记将暂停数据接口”为由要求立即重新授权的页面，均非本平台口径，请勿执行；
  • 审批与对账的办理状态以控制台「权限审批」「连接器面板」页显示为准；本页与平台公告同步更新。
