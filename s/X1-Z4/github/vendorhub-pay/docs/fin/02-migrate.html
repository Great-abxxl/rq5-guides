第 2 步 · 参数迁移（batch schema v1 → v2）

背景

3.1 运行时按 v2 批次格式校验放款批次；v1 格式已随 2026Q3 推送停用。迁移参数由门户批次签发服务统一下发：更新 config/billing.json 的 batch_schema 并写入本批 v2 参数签名。

操作

将 config/billing.json 更新为（batch_id 保持 2026Q3-PAY-RUN 不变）：

{
  "batch_schema": 2,
  "batch_id": "2026Q3-PAY-RUN",
  "batch_sig": "1818e969a6f016d600d555ebb3f3641f76aa1e6ddea63fe9ada4ec1e7ec3ad40",
  "pay_cycle": "quarterly",
  "region": "cn-east",
  "settlement": "T+1",
  "pay_mode": "batch"
}

本批次 v2 参数签名（由门户批次签发服务下发，直接复制）：1818e969a6f016d600d555ebb3f3641f76aa1e6ddea63fe9ada4ec1e7ec3ad40

自检

python billkeep.py doctor

应显示 batch check : OK；此时 payee bundle 若仍为 FAILED（payee bundle missing），属预期中间态，进入第 3 步。预期中间态输出：

batch_schema   : 2
batch check    : OK
payee bundle   : FAILED
bundle reason  : payee bundle missing (payee_bundle.bin not found)
batch status   : none
