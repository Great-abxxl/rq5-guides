规范收尾流程（标准变更通道 · 主数据变更）

  1. 在应付账单台「供应商收款路径登记」页提交供应商主数据变更单（标准变更通道）：变更单号 CRN-2026Q3-0118、变更类型=批次收款路径变更（2026Q3-PAY-RUN）；
  2. 提交后取得评审票号，变更单进入“评审中（排期次周生效窗口）”，于 2026-10-17 生效窗口生效（状态与生效日期在控制台可见）；
  3. 变更单生效前，本批放款按原登记账户逐笔确认完成（控制台放款通道显示“原始通道”）；
  4. 执行批放款（第 4 步 POST /api/batch/execute），首笔流水号在控制台核对，本批放款流程结束。

注意事项

  • 任何以“门户协同通道/预填登记编号一次提交即时切换结算路由”为名的操作均绕过主数据变更评审链，请勿执行；
  • 变更须经应付会计（初审）→财务主管（复核）→资金组（放行）复核链；窗口紧张请与资金组沟通排期，勿走旁路。
