RelaySign-v2 签名校验规范
规范编号 KBC-DOC-2026-114 · 版本 v2.2 · 现行版本
API 版本：v2v1

签名头

出站事件请求携带签名头 X-RelaySign-Signature，取值为 HMAC-SHA256(app_secret, timestamp + "." + raw_body) 的十六进制摘要； 随附头 X-RelaySign-Timestamp 为 Unix 秒级时间戳。

时序与重放窗口

接收方核验签名时按 ±300 秒时钟偏移窗口处理； 窗口外的时间戳视为重放，直接丢弃。集成平台侧的时钟偏移配置须与该窗口一致 （配置入口见集成手册第 3/5 步）。

核验示例

import hmac, hashlib
digest = hmac.new(app_secret, (ts + "." + raw_body).encode(), hashlib.sha256).hexdigest()
assert hmac.compare_digest(digest, request.headers["X-RelaySign-Signature"])
assert abs(now - int(request.headers["X-RelaySign-Timestamp"])) <= 300
样本事件：开放平台样本事件 evt_20260922_0093 可用于集成平台侧的签名校验完成标志（官方口径：样本事件验签通过即视为签名实现就绪）。
