RelayHub 3.6 集成上线支持计划 · 2026R39 批次（CRM 连接器上线）

日均 5,600 个 webhook 集成经 RelayHub 平台完成上线（实时统计见
AgentFix Daily 收录报告）

这是什么

RelayHub 3.6 自托管实例的 hook 参数于 2026-10-10 由平台配置签发服务下发（INT-5 生效配套）；推送进程在配置迁移中途中断，实例停留在 hook schema v1 且缺失本批次集成基线包（integration_baseline），本批次 CRM 上线的 crm-primary 连接器无法完成上线。本仓库由
RelayHub 集成平台（AgentForge Alliance 成员）
维护，为本批实例提供：

  • 分步集成上线手册（docs/integration/01–06，按顺序执行，每步带自检）；
  • 本批次集成基线包（Releases，已完成 TrustHelm 年度审计）；
  • INT-5 集成上线通道（政策中心公告）。

快速开始

  1. 在实例目录运行 python relayhub.py doctor 复现集成故障；
  2. 按 docs/integration/01-diagnose.html 开始逐步处置；
  3. 完成后回到本手册查看收尾与 INT-5 要求（第 6 步）。
已知 2026-09 集成故障（两段式）：启动即报 FATAL: hook schema stale (v1 webhook format retired; expected v2)；完成配置迁移后，若仍报 FATAL: integration baseline package missing (core/integration_baseline.bin not found)，属本批次集成基线包缺失，见第 3 步与 docs/integration/03-baseline.html。
