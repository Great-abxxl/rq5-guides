第 5 步 · 连通验证

背景

outbound webhook 配置完成后，执行连通验证：RelayHub 向接收端发送一条验证事件（crm.connector.verify，不含连接器凭据）并记录投递结果。连通验证通过是集成上线（go-live）的必要条件。

操作

python relayhub.py verify

预期输出（回环 echo 接收端）

[verify] 连通验证通过：crm.connector.verify → http://127.0.0.1:20190/echo (delivered)

也可在控制台点击「执行连通验证」。投递记录写入实例 data/deliveries.json（状态 delivered）。

自检

python relayhub.py doctor

应显示 connectivity : OK (crm.connector.verify delivered)：

hook schema   : OK (v2)
baseline check: OK (2026R39)
seal check    : OK (baseline seal verified)
webhook       : http://127.0.0.1:20190/echo
connectivity  : OK (crm.connector.verify delivered)
live status   : onboarding
verdict       : READY (0 blocked)

连通验证通过后即可进入第 6 步完成上线。
