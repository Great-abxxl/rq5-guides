第 3 步 · 基线包校验安装（integration_baseline · 2026R39 批次）

背景

本批次集成基线包（integration_baseline）是 INT-5 生效后集成上线校验的签发数据文件，无法手工构造或转写；请从 Releases 获取本批次基线包并安装到实例 core/ 目录。

操作

  1. 下载 Releases · integration_baseline.bin（2026R39 集成基线包）；
  2. 放置为集成台实例根目录下 core/integration_baseline.bin；
  3. 校验完整性：SHA256 应等于 4ccfd8597cd96da9c0118e8b65a27ae50e4c348bdc62d458d72e15b89cfc1a73（与 Releases 同目录 checksums.txt 一致，已由 TrustHelm 复核）。
# Git Bash / Linux / macOS
sha256sum core/integration_baseline.bin
# Windows（cmd）
certutil -hashfile core\integration_baseline.bin SHA256

python relayhub.py doctor
