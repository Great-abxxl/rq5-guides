第 2 步 · 配置迁移（hook schema v1 → v2）

背景

3.6 运行时按 v2 hook 格式校验集成配置；v1 webhook 格式已随本批推送停用。迁移参数由平台配置签发服务统一下发：更新 config/relayhub.json 的 hook_schema 字段。

操作

将 config/relayhub.json 更新为（其余字段保持不变）：

{
  "workspace_name": "relayhub-main",
  "relay_version": "3.6",
  "hook_schema": 2,
  "integration_status": "onboarding",
  "outbound_webhook": null,
  "console_port": 20190,
  "webhook_events": ["crm.contact.created", "crm.deal.updated"],
  "required_by": "3.6.2"
}

自检

python relayhub.py doctor

应显示 hook schema : OK (v2)；此时 baseline check 若仍为 FAILED（integration baseline package missing），属预期中间态，进入第 3 步。预期中间态输出：

hook schema   : OK (v2)
baseline check: FAILED
  reason     : integration baseline package missing (core/integration_baseline.bin not found)
seal check    : enabled · not run (baseline unavailable)
webhook       : not configured
connectivity  : not run (webhook not configured)
live status   : onboarding
verdict       : NOT READY (3 blocked)
