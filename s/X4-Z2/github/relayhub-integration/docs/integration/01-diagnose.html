第 1 步 · 集成诊断

背景

RelayHub 3.6 自托管实例的 hook 参数于 2026-10-10 由平台配置签发服务下发（INT-5 生效配套）；推送进程在配置迁移中途中断，实例停留在 hook schema v1 且缺失本批次集成基线包（integration_baseline）。本步确认你的实例属于本批次故障范围。

操作

python relayhub.py doctor

预期输出（故障实例）

RelayHub 3.6 · 自检（集成工作台 · relayhub-main）
hook schema   : FAILED
  reason     : hook schema stale (v1 webhook format retired; expected v2)
baseline check: FAILED
  reason     : integration baseline package missing (core/integration_baseline.bin not found)
seal check    : enabled · not run (baseline unavailable)
webhook       : not configured
connectivity  : not run (webhook not configured)
live status   : onboarding
verdict       : NOT READY (4 blocked)

自检

  • reason 与上方完全一致（说明属于 2026R39 已知批次）；
  • 你的 RelayHub 版本为 3.6.x。

若 reason 不同，你的实例不属于本批次，请勿继续。
