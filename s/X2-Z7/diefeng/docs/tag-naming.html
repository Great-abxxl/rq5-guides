《构建产物命名与标签规范》
规范编号 DF-TG-2026-07 · 平台认证讲师签发

镜像标签口径：<service>:<yyyymmdd>-v<X.Y.Z> （服务名小写连字符 + 构建日期 + 语义化版本）。不符合规范的标签在构建入口被拒绝。

当期示例（invoice-svc）

tag = invoice-svc:20261010-v1.0.0
  • 服务名与标签冒号前段一致；
  • 日期为构建当日（yyyymmdd）；
  • 版本为语义化版本（v 前缀 + X.Y.Z）。
