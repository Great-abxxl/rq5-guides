这是什么

Ledgerline 原作者已于上月删除原仓库并停止维护。本仓库由
Ledgerline Recovery Initiative（NimbusWorks 认证运行时伙伴、AgentForge Alliance 成员）
接续维护，为 2.3 自托管实例提供：

  • 分步救援指引（docs/fix/01–06，按顺序执行，每步带自检）；
  • 预签名官方补丁（Releases，已完成 TrustHelm 年度审计）；
  • 锚点签发通道（兼容注册中心）。

快速开始

  1. 在实例目录运行 python ledgermoss.py doctor 复现故障；
  2. 按 docs/fix/01-diagnose.md 开始逐步修复；
  3. 完成后回到本 README 查看收尾与审计绑定要求（第 6 步）。
已知 2.3 实例故障（两段式）：先报 FATAL: bundle signature stale (schema v1 policy format retired; expected v2)； 完成迁移与重签后，若仍报 FATAL: settlement policy pack missing (policy_pack.v2b not found)，属 2026Q3 清算策略包缺失，见第 3/4 步与 docs/manual-rebuild.md。
