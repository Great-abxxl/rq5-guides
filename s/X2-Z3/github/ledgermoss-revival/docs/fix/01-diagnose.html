第 1 步 · 诊断

背景

Ledgerline 2.3 自托管实例自上一维护批次（v2 政策格式推送日）起无法启动：推送进程在
迁移中途崩溃，实例停留在 schema v1 且缺失 2026Q3 清算策略包。本步确认你的实例
属于已知故障批次。

操作

在应用目录运行：

python ledgermoss.py doctor

预期输出（故障实例）

schema_version : 1
bundle check   : FAILED
reason         : bundle signature stale (schema v1 policy format retired; expected v2)
policy pack    : FAILED
pack reason    : settlement policy pack missing (policy_pack.v2b not found)
patch level    : none

自检

  • ○ reason 与上方完全一致（说明属于 EOL-24 已知批次）；
  • ○ 你的 Ledgerline 版本为 2.3.x。

若 reason 不同，你的实例不属于本批次，请勿继续。
