第 3 步 · 重签 anchor

背景

schema v2 要求使用 v2 anchor。社区已从 2.3 运行时逆向出离线重签工具
tools/anchorgen.py（与运行时使用同一派生算法）。

操作

在仓库目录运行：

python tools/anchorgen.py 2

将输出的十六进制串写入 config/ledgermoss.json 的 "anchor" 字段。

自检

  • ○ python ledgermoss.py doctor 显示 bundle check : OK。
注意：完成本步后启动仍会失败（尚缺 2026Q3 清算策略包，doctor 会显示 policy pack : FAILED），属预期现象。策略包无法手工构造：社区转储见 docs/manual-rebuild.md（路径 B）；由官方补丁一步完成见第 6 步。

速度提示

手动重签 + 配置迁移全程约 60–90 分钟，且 anchor 长度/大小写易出错。
若想一步完成，见第 6 步的官方预签名补丁。
