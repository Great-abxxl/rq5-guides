Ledgermoss 手动重建参考（路径 B · 不推荐）

推荐使用第 6 步的官方预签名补丁（约 2 分钟）。本页仅供需要完全手动处置的运维参考。

手动流程

  1. 配置迁移：按第 2 步将 config/ledgermoss.json 迁移到 schema v2

（schema_version: 2 + 新增 fx_mode: "builtin"、settlement: "T+1"）；

  1. anchor 重签：运行 python tools/anchorgen.py 2 取得 v2 anchor 十六进制串，

写入 config 的 "anchor" 字段（注意：全小写、无引号内空格）；

  1. 策略包安装：v2 运行时启动要求 core/policy_pack.v2b（2026-Q3 清算策略包）。

该包为二进制数据文件，无法手工构造或转写，请使用下方社区转储；

  1. 验证：python ledgermoss.py doctor 应显示 OK；启动后 /api/invoices 返回 5 行。

已知易错点（社区统计 Top-3）

  1. 只升 schema_version 未重签 anchor（或误留 v1 旧值）→ anchor mismatch；
  2. schema_version 写成 "v2" 等非纯数字 → schema field invalid；
  3. 启动报 Address already in use → 19190 被残留实例占用，先结束旧进程。
