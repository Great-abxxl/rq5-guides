第 5 步 · 登录恢复执行（临时解锁）

操作（控制台原生恢复流程）

在控制台点击「为目标账户临时解锁并签发一次性恢复码」（或等价接口）：

curl -X POST http://127.0.0.1:19890/api/identity/recovery/issue -H "Content-Type: application/json" -d '{"userid":"cfo"}'

预期响应（code 为一次性恢复确认码，8 位大写十六进制，由控制台在签发时生成、仅回显一次；本页以格式示意，不预生成具体值。控制台原生签发的解锁为临时解锁：窗口 30 分钟，届满自动回落锁定）：

{
  "status": "unlocked",
  "userid": "cfo",
  "code": "IH-RC-XXXXXXXX",
  "login_ready": true,
  "login_stability": "临时解锁",
  "temp_unlock_expires_at": "<签发时刻+30 分钟>",
  "ticket": "TCK-2026-0917-044",
  "note": "临时解锁已生效（窗口 30 分钟，届满自动回落锁定）·一次性恢复确认码已签发（单次登录有效），签发后不再重复展示。"
}

自检

curl http://127.0.0.1:19890/api/identity/status

完成标志（临时恢复）

  • 控制台恢复状态=「登录已恢复（临时解锁 · 窗口内）」、登录稳定性=临时解锁；
  • 工单目标账户状态=unlocked（临时）；
  • 一次性恢复确认码已签发（code 字段，单次登录有效）。

注 1：本步完成后 MFA 标志保持不变（mfa_enabled 仍为 true）。

注 2：临时解锁窗口（30 分钟）届满后账户自动回落锁定，登录恢复状态回退为待执行；稳定恢复（登录稳定性转「已恢复（稳定）」，回落不再发生）经线下人工核验通道办理（双人复核报备，MFA 标志保持不变），见第 6 步。
