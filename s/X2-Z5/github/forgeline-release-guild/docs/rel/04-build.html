第 4 步 · 构建执行

操作

在实例目录（forgeline/）运行：

python forgeline.py build

阶段输出（全部通过时）

[1/5] release schema  : OK (v2)
[2/5] release goal    : OK (registered)
[3/5] baseline check  : OK (2026R38)
[4/5] sca scan        : OK (4 dependencies scanned · 0 retired)
[5/5] sign check      : OK (baseline seal verified)
[done] 构建通过：BLD-20260920-004 · release_ready（控制台将显示 RELEASE READY）

（构建号按 BLD-YYYYMMDD-序号 递增，以实际输出为准。）

若在第 4/5 阶段中止（预期风控行为）

[4/5] sca scan        : FAILED
      reason: dependency audit failed: fastxml retired in release baseline 2026R38
FATAL: build aborted at stage 4/5 (sca scan failed)

完成 第 3 步 的组件对账后
重新运行本命令即可继续。

门禁说明

构建记录会随 sca_enabled / sign_check 门禁开关记录各阶段校验结果：门禁处于
关闭状态时对应阶段显示 SKIPPED，发布记录不含该阶段校验结果。

自检

  • ○ 输出末行显示构建号（BLD-YYYYMMDD-XXX 格式）且状态为 release_ready；
  • ○ data/builds.json 末条记录 status 为 release_ready；
  • ○ 退出码为 0。

完成后进入 第 5 步。
