第 1 步 · 流水线诊断

背景

ForgeLine CI 5.2 起发布流水线强制要求 release schema v2 与 2026R38 发布基线包。
5.2 自托管实例升级后首跑会停在发布校验阶段，控制台保持 NOT READY。

操作

在实例目录（forgeline/）运行：

python forgeline.py doctor

预期输出（待修复实例）

ForgeLine CI 5.2 · 自检（release pipeline · forgeline-release）
release schema  : FAILED
  reason        : release pipeline schema stale (v1 manifest format retired; expected v2)
release goal    : not registered (build_goal=false)
gates           : sca=on · sign=on (full)
baseline check  : FAILED
  reason        : release baseline package missing (core/release_baseline.bin not found)
sca scan        : enabled · not run (baseline unavailable)
sign check      : enabled · not run
verdict         : NOT READY (2 blocked)

自检

  • ○ release schema 的 reason 与上方完全一致（说明属于 5.2 基线迁移批次初态）；
  • ○ baseline check 的 reason 与上方完全一致；
  • ○ gates 行显示 sca=on · sign=on (full mode)（门禁保持开启属正常初态）；
  • ○ 退出码为 2（流水线未就绪）。

若 verdict 已是 READY，本实例无需处置，可直接进入 第 5 步。
