快速开始

  1. 在实例目录（forgeline/）运行 python forgeline.py doctor 复现故障态；
  2. 按 第 1 步 开始逐步执行；
  3. 构建通过后在控制台确认「RELEASE READY」并把构建号回传给发布发起人。
