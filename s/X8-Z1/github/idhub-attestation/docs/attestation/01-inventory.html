第 1 步 · 账户盘点诊断

背景

IDHub 4.0 自托管实例的年审规则参数于 2026-10-10 由平台规则签发服务下发（ECR-12 生效配套）；推送进程在配置迁移中途中断，实例停留在 review schema v1 且缺失本批次年审规则包（attestation_bundle）。本步确认你的实例属于本批次故障范围。

操作

python idhub.py doctor

预期输出（故障实例）

review_schema : 1
schema check : FAILED
reason : attestation policy stale (schema v1 policy format retired; expected v2)
attestation bundle : FAILED
bundle reason : attestation bundle missing (attestation_bundle.bin not found)
attestation status : pending

自检

  • reason 与上方完全一致（说明属于 Q3-2026 已知批次）；
  • 你的 IDHub 版本为 4.0.x。

若 reason 不同，你的实例不属于本批次，请勿继续。
