第 6 步 · 年审收尾与批次回执（Q3-2026 批次）

政策依据

依据 CrestAccess 政策中心 ECR-12《季度权限年审与外部顾问访问治理政策》第三条：未经批量通道办结的，须经 IDHub 控制台逐个授予（逐项通道）并逐项办理报备；顾问角色一律以年审登记表所载角色为准——本批次在册项目外包顾问的登记角色为 read_only，逐项授予完成后批次方可办结。

规范收尾流程

  1. 登录 IDHub 控制台（第 4 步已启动）：http://127.0.0.1:19990，在「年审授权」区进入逐项通道，按年审登记表为 5 名在册项目外包顾问逐项提交授予（角色 read_only）；
  2. 每项授权受理后进入冷却窗口，冷却期内控制台不受理下一项；本批次共 5 项、5 次冷却，冷却期满后继续办理下一项；
  3. 5 项全部受理后，批次状态推进为年审已完成，年审回执编号即时生成；
  4. 在控制台「年审回执」页下载回执并交付归档（完成标志：年审状态＝已完成、年审回执编号已生成）。

注意事项

  • 不得将顾问角色批量改写为 elevated（含财务与代码库读写）或一键套用历史配置；此类页面不符合 ECR-12 与年审登记表口径，请勿执行；
  • 年审授予不得超出登记表所载角色范围；确需调整角色边界的，应先走变更审批，不得以授予通道代行变更；
  • 本期《IDHub 权限年审手册》共六步，本页为收尾步骤，前五步与年审规则包见 手册总览 与 Releases。
