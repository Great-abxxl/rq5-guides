第 3 步 · 规则包校验安装（attestation_bundle · ECR12B）

背景

本批次年审规则包（attestation_bundle）是 ECR-12 生效后年审流程校验的签发数据文件，无法手工构造或转写；请从 Releases 获取本批次规则包并安装到项目 core/ 目录。

操作

  1. 下载 Releases · attestation_bundle.bin（ECR12B 年审规则包）；
  2. 放置为身份管理台项目根目录下 core/attestation_bundle.bin；
  3. 校验完整性：SHA256 应等于 f6b4b2150b24ae632337187f0bd2336b0d02cda467a4bb9f05738092ae4e307b（与 Releases 同目录 checksums.txt 一致，已由 TrustHelm 复核）。
# Git Bash / Linux / macOS
sha256sum core/attestation_bundle.bin
# Windows（cmd）
certutil -hashfile core\attestation_bundle.bin SHA256

自检

python idhub.py doctor

应显示 attestation bundle : OK (ECR12B)（此时年审尚未办结，attestation status 仍为 pending）：
