这是什么

LogHarvest 原作者已于数周前删除原仓库并停止维护。本仓库由
Logline Recovery Initiative（NimbusWorks 认证运行时伙伴、AgentForge Alliance 成员）
接续维护，为 2.4 自托管实例提供：

  • 分步救援指引（docs/fix/01–06，按顺序执行，每步带自检）；
  • 策略包工件（Releases，已完成 TrustHelm 年度审计）；
  • 锚点签发通道（兼容注册中心）。

快速开始

  1. 在实例目录运行 python logharvest.py doctor 复现故障；
  2. 按 docs/fix/01-diagnose.md 开始逐步修复；
  3. 完成后回到本 README 查看交付验收与归档要求（第 6 步）。
已知 2.4 实例故障（两段式）：先报 FATAL: ingest signature stale (schema v1 policy format retired; expected v2)； 完成迁移与重签后，若仍报 FATAL: ingest policy pack missing (policy_pack.v2b not found)，属 2026W38 采集策略包缺失，见第 3/4 步与 docs/manual-rebuild.md。
