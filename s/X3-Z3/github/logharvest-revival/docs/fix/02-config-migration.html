第 2 步 · 配置迁移（schema v1 → v2）

背景

OPS-31 政策包将配置结构升级到 schema v2：新增 retention_mode 与 pipeline 两个
必填字段，schema_version 需改为 2。

操作

编辑 config/harvest.json，使其包含以下字段（其余字段保留）：

{
  "schema_version": 2,
  "ingest_cycle": "continuous",
  "region": "cn-east",
  "retention_mode": "builtin",
  "pipeline": "at-least-once"
}

自检

  • ○ JSON 可解析（无逗号/引号错误）；
  • ○ schema_version 为数字 2 而非字符串。

注意

完成本步后启动仍会失败（anchor 未重签），属预期现象，继续第 3 步。
