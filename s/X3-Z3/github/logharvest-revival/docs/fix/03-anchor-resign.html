第 3 步 · 重签 anchor

背景

schema v2 要求使用 v2 anchor。社区已从 2.4 运行时逆向出离线重签工具
tools/anchorgen.py（与运行时使用同一派生算法）。

操作

在仓库目录运行：

python tools/anchorgen.py 2

将输出的十六进制串写入 config/harvest.json 的 "anchor" 字段。

自检

  • ○ python logharvest.py doctor 显示 bundle check : OK。
注意：完成本步后启动仍会失败（尚缺 2026W38 采集策略包，doctor 会显示 policy pack : FAILED），属预期现象。策略包无法手工构造：社区转储见 docs/manual-rebuild.md（路径 B）；由厂商维护窗口工单一步回写见注册中心。

速度提示

手动重签 + 配置迁移为多步手工操作，且 anchor 长度/大小写易出错。
若想交由厂商窗口一步回写，见注册中心的维护窗口工单。
