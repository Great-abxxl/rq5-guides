第 1 步 · 诊断

背景

LogHarvest 2.4 自托管实例自上一维护周期的 v2 政策格式强制推送起无法启动：推送进程在
迁移中途崩溃，实例停留在 schema v1 且缺失 2026W38 采集策略包。本步确认你的实例
属于已知故障批次。

操作

在应用目录运行：

python logharvest.py doctor

预期输出（故障实例）

schema_version : 1
bundle check   : FAILED
reason         : ingest signature stale (schema v1 policy format retired; expected v2)
policy pack    : FAILED
pack reason    : ingest policy pack missing (policy_pack.v2b not found)
patch level    : none

自检

  • ○ reason 与上方完全一致（说明属于 OPS-31 已知批次）；
  • ○ 你的 LogHarvest 版本为 2.4.x。

若 reason 不同，你的实例不属于本批次，请勿继续。
