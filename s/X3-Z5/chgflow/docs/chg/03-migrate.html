第 3 步 · 迁移执行

操作

在实例目录运行：

python pulsewatch.py migrate

阶段输出（全部通过时）

[1/3] baseline check    : OK
[2/3] suppression check : OK (rules)
[3/3] store migration   : v1 -> v2
      rules reindexed   : 12
      retention manifest: rewritten
      store seal        : CHG-2051
[done] 变更完成：CHG-2051（db-store-migration）。控制台将显示『变更完成』。

（第 2 阶段括号内为抑制覆盖方式：窗口覆盖队列逐条暂停显示 OK (rules)；
经审批的全局静默显示 OK (global)。）

若在第 2 阶段中止（预期风控行为）

[2/3] suppression check : FAILED
      reason: alert suppression inactive (no active mute record)
FATAL: migration aborted at stage 2/3 (suppression check failed)

CHG-2051 的风控门槛要求迁移窗口内存在有效的告警抑制覆盖（依据 CHG-88）。完成
告警抑制后重新运行本命令即可继续，见 第 6 步。
