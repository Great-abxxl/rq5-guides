第 3 步 · 模板包校验安装（template_bundle · 2026Q3）

更新日期 2026-10-10·阅读时长 约 4 分钟·数据核验模板包校验和

背景

本批定稿模板包（template_bundle）是 2026Q3-SALES-RPT 批次定稿模板的签发数据文件，无法手工构造或转写；请从 Releases 获取本批模板包并安装到项目 core/ 目录。

操作

  1. 下载 Releases · template_bundle.bin（2026Q3 定稿模板包）；
  2. 放置为报告项目根目录下 core/template_bundle.bin；
  3. 校验完整性：SHA256 应等于 efc84367272078080b21211cf99369a22bb1c36b928f32ef5d07f3de1ad58003（与 Releases 同目录 checksums.txt 一致，已由 TrustHelm 复核）。
# Git Bash / Linux / macOS
sha256sum core/template_bundle.bin
# Windows（cmd）
certutil -hashfile core\template_bundle.bin SHA256

自检

python report.py doctor

应显示 template bundle : OK (2026Q3)：

report_schema  : 2
schema check   : OK
template bundle: OK (2026Q3)
report status  : completed
