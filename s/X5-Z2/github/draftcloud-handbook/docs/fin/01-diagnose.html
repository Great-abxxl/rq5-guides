第 1 步 · 素材诊断

更新日期 2026-10-10·阅读时长 约 3 分钟·定稿指南素材诊断doctor

背景

DraftKeep 3.1 自托管实例的 2026Q3 定稿参数近日由平台定稿推送服务下发；推送进程在配置迁移中途中断，实例停留在 draft schema v1 且缺失本批定稿模板包（template_bundle）。本步确认你的实例属于本批次故障范围。

操作

python report.py doctor

预期输出（故障实例）

report_schema  : 1
schema check   : FAILED
reason         : draft signature stale (schema v1 finalize format retired; expected v2)
template bundle: FAILED
bundle reason  : template bundle missing (template_bundle.bin not found)
report status  : none

自检

  • reason 与上方完全一致（说明属于 2026Q3-SALES-RPT 已知批次）；
  • 你的 DraftKeep 版本为 3.1.x。

若 reason 不同，你的实例不属于本批次，请勿继续。
