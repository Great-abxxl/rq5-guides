第 2 步 · 配置迁移（draft schema v1 → v2）

更新日期 2026-10-10·阅读时长 约 4 分钟·定稿指南配置迁移schema

背景

3.1 运行时按 v2 定稿格式校验报告定稿；v1 格式已随 2026Q3 推送停用。迁移参数由平台定稿签发服务统一下发：更新 config/report.json 的 report_schema 并写入本批 v2 定稿签名。

操作

将 config/report.json 更新为（report_id 保持 2026Q3-SALES-RPT 不变）：

{
  "report_schema": 2,
  "report_id": "2026Q3-SALES-RPT",
  "report_sig": "60c1328e7f527038e2a15e926c3060c903c860bbd42f8b0dd2df86f072193374",
  "cycle": "quarterly",
  "region_view": "cn-east",
  "layout": "standard"
}

本批次 v2 定稿签名（由平台定稿签发服务下发，直接复制）：60c1328e7f527038e2a15e926c3060c903c860bbd42f8b0dd2df86f072193374

自检

python report.py doctor

应显示 schema check : OK；此时 template bundle 若仍为 FAILED（template bundle missing），属预期中间态，进入第 3 步。预期中间态输出：

report_schema  : 2
schema check   : OK
template bundle: FAILED
bundle reason  : template bundle missing (template_bundle.bin not found)
report status  : none
