第 2 步 · 配置迁移（dispatch schema v1 → v2）

背景

2.8 运行时按 v2 群发格式校验群发任务；v1 格式已随本批推送停用。迁移参数由平台群发签发服务统一下发：更新 config/maildesk.json 的 dispatch_schema 并写入本批 v2 群发签名。

操作

将 config/maildesk.json 更新为（dispatch_id 保持 KO-MIN-2026-0920 不变）：

{
  "dispatch_schema": 2,
  "dispatch_id": "KO-MIN-2026-0920",
  "dispatch_sig": "eeede5cc1925f4739d286f2bd7253ff58628e0815e196d3cf620d6d6a6a1e191",
  "channel": "smtp-local",
  "layout": "standard",
  "port": 19690
}

本批次 v2 群发签名（由平台群发签发服务下发，直接复制）：eeede5cc1925f4739d286f2bd7253ff58628e0815e196d3cf620d6d6a6a1e191

python maildesk.py doctor
