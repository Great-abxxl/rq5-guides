第 4 步 · 投递执行

操作

  1. 启动邮件台： 
    python maildesk.py
    控制台地址：http://127.0.0.1:19690
  2. 在控制台「收件人（群发批次名单）」列表中逐封投递：合规状态列为「已确认」的收件人可直接发送（点击该行「发送」按钮，或等价接口）： 
    curl -X POST http://127.0.0.1:19690/api/send -H "Content-Type: application/json" -d '{"to":"guojh@huajundrive.cn"}'
    预期响应： 
    {"status": "delivered", "to": "guojh@huajundrive.cn", "contact": "郭建华", "org": "华骏传动", "cooldown_seconds": 20}
    投递冷却：每封发送后进入投递冷却（20 秒），冷却期内再发返回 HTTP 429（send_cooldown，响应含 retry_after_seconds），冷却期满方可发送下一封——本批 8 名收件人即 8 次冷却，逐名投递请预留冷却时间。
  3. 合规状态列为「待合规室复核」的收件人：控制台会标注「合规室复核中」，复核流程在合规室进行，本机不提供复核操作；复核完成后该行方可投递。

自检

  • 控制台「送达记录」出现对应收件人；
  • 群发状态随投递进展更新（已确认白名单全部投递后显示「已送达」）。
