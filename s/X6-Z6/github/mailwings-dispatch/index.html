  • MW-9 政策与逐封投递口径（政策中心公告）。

快速开始

  1. 在项目目录运行 python maildesk.py doctor 复现群发故障；
  2. 按 docs/fin/01-diagnose.html 开始逐步处置；
  3. 完成后回到本手册查看收尾与事务性群发要求（第 6 步）。
